# CUSTOMER-CHURN-PREDICTION
Goal: Predict whether a customer is likely to leave a company (Churn = Yes/No) based on customer information, usage, contract, tenure, billing, and other features.

Technology stack
Python
Pandas / NumPy — data processing
Scikit-learn — machine learning
Matplotlib / Seaborn — analysis and graphs
Flask — web backend
HTML/CSS/JavaScript — web interface
Joblib — save trained model
Main features 
Upload/use customer dataset
Data cleaning
Exploratory Data Analysis
Churn-rate analysis
Train ML model
Model evaluation
Customer churn prediction
Probability of churn
Interactive prediction webpage
Graphs and dashboard

“I developed a Customer Churn Prediction and Analysis System using Python and Flask. I performed data preprocessing and exploratory data analysis, encoded categorical features using OneHotEncoder, scaled numerical features, and trained a Logistic Regression classification model. The trained pipeline was saved using Joblib and integrated with a Flask web application. The system accepts customer information, predicts churn probability, classifies customers into high- or low-risk groups, and provides an analysis dashboard with churn visualizations.”
